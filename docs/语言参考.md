## 1. 第一个程序

```python
# hello.ae
print("你好，五行！")
```

```
aether run hello.ae
```

源文件使用 UTF-8 编码，扩展名为 `.ae`。模块顶层的语句按顺序执行；如果主模块定义了 `def main()`，它会在顶层语句之后被调用（`aether test` 时不调用）。

## 2. 词法结构

### 注释与缩进

`#` 开始一行注释。代码块由缩进表示（与 Python 相同），同一文件中不能混用 Tab 和空格缩进。冒号后面也可以直接写一条简单语句：`if x > 0: print(x)`。

一行写多条语句用 `;` 分隔。

### 续行

- 圆括号、方括号、花括号内部可以自由换行；
- 行末的 `\` 把下一行接到本行；
- **以 `.` 或 `?.` 开头的行**会接到上一行，方便写链式调用：

```python
result = [5, 3, 8, 1]
    .filter(x => x > 2)
    .map(x => x * 10)
    .sorted()
```

### 标识符

由字母（包括汉字等 Unicode 字母）、数字和下划线组成，不能以数字开头：`count`、`_cache`、`用户列表` 都是合法的标识符。以 `_` 开头的名字是私有的（见第 8、18 节）。

### 关键字

```
and as assert async await break class const continue def defer del elif else
enum except extend false finally for from go if import in interface is not
null or pass raise return struct true try while with yield
```

以下单词只在特定位置有特殊含义，其余时候可以用作普通名字：
`match` `case` `select` `default` `prop` `get` `set` `test` `static` `abstract` `override` `global` `nonlocal`。

### 字面量

| 种类 | 例子 |
|---|---|
| 整数 | `42`、`1_000_000`、`0xff`、`0b1010`、`0o17` |
| 浮点数 | `3.14`、`2.5e-3`、`1e10` |
| 布尔 | `true`、`false` |
| 空值 | `null` |
| 字符 `char` | `'a'`、`'中'`、`'\n'`、`'\u4e2d'` |
| 字符串 `str` | `"你好"`、`"换行\n"`、`"""多行字符串"""` |
| 原始字符串 | `r"C:\路径\不转义"` |
| f-字符串 | `f"x = {x}, 两位小数 {pi:.2f}, 调试 {x=}, repr {s!r}"` |

**单引号表示字符，字符串必须用双引号。** 相邻的字符串字面量会自动拼接。

转义序列：`\n \t \r \\ \" \' \0 \a \b \f \v \e \xHH \uHHHH \u{H...} \UHHHHHHHH`。

f-字符串的 `{}` 中可以写任意表达式（可以包含双引号字符串，例如 `f"{", ".join(xs)}"`），`{{` 与 `}}` 表示字面的花括号。格式说明与 Python 相同：

```python
f"{n:05d} {x:>8.3f} {s:^10} {1234567:,} {0.25:.1%} {255:#x} {name!r}"
```

## 3. 类型

### 基本类型

| 类型 | 说明 |
|---|---|
| `int` | 64 位有符号整数（别名 `i64`），溢出时回绕 |
| `i8` `i16` `i32` | 有符号整数 |
| `u8`（`byte`）`u16` `u32` `u64` | 无符号整数 |
| `float` | 64 位浮点数（别名 `f64`） |
| `f32` | 32 位浮点数 |
| `bool` | `true` / `false` |
| `str` | 不可变的 Unicode 字符串；`len` 与下标按字符（码点）计算 |
| `char` | 一个 Unicode 字符 |
| `any` | 任意类型的值（可以为 `null`），使用前需要 `as` 转换或 `is` 判断 |

### 复合类型

| 写法 | 说明 |
|---|---|
| `list[T]` | 可变列表（引用语义） |
| `dict[K, V]` | 字典，**保持插入顺序**；键必须可哈希 |
| `set[T]` | 集合，保持插入顺序 |
| `(A, B, ...)` | 元组（2 到 8 个元素，不可变，按值比较） |
| `T?` | 可空类型：`T` 或 `null` |
| `fn(A, B) -> R` | 函数类型；没有返回值时省略 `-> R` |
| `chan[T]` | 通道 |
| `iter[T]` | 迭代器（生成器函数和生成器表达式的结果） |
| `Task[T]` | `async` 函数调用的结果 |

“可哈希”的类型：数字、`bool`、`str`、`char`、枚举、元组与结构体（成员都可哈希时）、类（按对象身份）。列表、字典、集合不可哈希。

### 类型推断与转换

变量的类型从初始值推断；空容器、`null` 等无法推断的值需要写出类型：

```python
xs: list[int] = []
name: str? = null
```

隐式转换只有“不会丢失信息”的几种：

- 整数拓宽：`i8 → i16 → i32 → int`，`u8 → u16 → u32 → u64`，无符号到更大的有符号；
- 整数到浮点数、`f32` 到 `float`；
- `T` 到 `T?`、`null` 到 `T?`；
- 子类到基类、实现了接口的类型到接口；
- 任何值到 `any`；
- `list[T]` / `set[T]` / `dict[K, V]`（键）/ `str`（字符）/ `chan[T]` / 有 `__iter__` 的类型 到 `iter[T]`。

其它转换需要显式写出：

```python
int("42")      int(3.9)       float("2.5")    str(123)     bool(0)
char(65)       ord('A')       chr(65)         x as float   obj as Dog
```

`bool(x)` 与条件中的真值判断规则相同（可空值、字符串、容器，以及定义了 `__bool__` 或 `__len__` 的对象）。上面列出的隐式转换也可以用 `as` 显式写出，例如 `null as str?`、`xs as iter[int]`、`x as any`。

### 类型别名

`type 名字 = 类型` 给类型起一个别名，别名与原类型完全相同（可以互相赋值）。别名可以带类型参数和约束：

```python
type Graph = dict[str, list[(str, int)]]
type Pair[T] = (T, T)
type Counter[K: Hashable] = dict[K, int]
type Callback = fn(int) -> str

def neighbors(g: Graph, n: str) -> list[str]: ...
p: Pair[float] = (0.5, 1.5)
g = Graph()                   # 等价于 dict[str, list[(str, int)]]()
```

类型别名只能定义在模块顶层，可以被其它模块导入（`from geo import Point2`、`geo.Point2`）；以 `_` 开头的别名是模块私有的。别名不能直接或间接地引用自己，递归的数据结构请用 `class`。

## 4. 变量、常量与作用域

### 赋值即声明

第一次给一个名字赋值就声明了变量，之后的赋值必须是同一类型：

```python
count = 0          # 声明 int 变量
count = count + 1
count = "一"       # 错误：不能把 str 赋给 int 类型的变量
```

`名字: 类型 = 值` 显式声明变量（也可以只写 `名字: 类型`，稍后再赋值）。

### 解构赋值

```python
a, b = b, a                      # 交换（右边先全部求值）
q, r = divmod2(17, 5)            # 元组：个数必须一致
x, y = [1, 2]                    # 列表：运行时检查长度，不一致时抛出 ValueError
first, *rest = [1, 2, 3, 4]      # rest == [2, 3, 4]
first, *mid, last = "hello"      # 字符串、range 等可迭代对象先收集为列表：mid == ['e', 'l', 'l']
head, *tail = (1, 2, 3)          # 元组的剩余元素（类型须一致）收集为列表
for name, *scores in rows:       # 循环变量也可以解构（元组或列表）
    ...
```

解构的目标中最多只能有一个 `*`。

### 赋值表达式 :=

`(名字 := 值)` 给变量赋值，整个表达式的值就是赋的值（Python 的“海象运算符”）。它遵循与 `=` 相同的规则：第一次赋值即在函数级作用域声明变量（在推导式中使用时，变量属于外层函数）。

```python
if (n := len(items)) > 10:
    print(f"太多了：{n} 个")

while (line := f.read_line()) != null:
    print(line.upper())          # line 在循环体中窄化为 str

if m := re.match(r"(\d+)-(\d+)", s):
    print(m.group(1))            # m 不为 null

big = [y for x in data if (y := f(x)) > 0]
```

`:=` 出现在 `and`/`or` 的右侧、条件表达式的分支或推导式中时，只有确实执行到它的路径上变量才算已赋值：`if ok and (v := f()) > 0:` 的分支中可以使用 `v`，但 `if ok or (v := f()) > 0:` 之后不行。`:=` 不能单独作为语句（请写 `x = 值`），也不能用在 lambda 中。

### 作用域

- 函数内的变量是**函数作用域**的（与 Python 相同）：在 `if` 或循环体中声明的变量，在其后的代码中也可见；
- **循环变量、推导式变量、`except ... as e`、`with ... as x`、`match` 绑定的变量是块作用域的**，而且每次迭代都是新的变量（闭包捕获的是当次的值）；
- 模块顶层的变量是全局变量，函数中可以直接读取。

### global

函数中给模块级变量赋值时，默认会创建一个同名的局部变量（与 Python 相同）。要修改全局变量，需要先声明：

```python
total = 0
def add(n: int):
    global total
    total += n
```

嵌套函数和 lambda 可以直接读取、修改外层函数的变量（不需要 `nonlocal`）。

### 确定赋值

使用一个可能没有被赋值的变量是编译错误：

```python
if ok:
    v = 1
print(v)     # 错误：变量 v 可能还没有被赋值
```

### 常量

```python
const MAX = 100
const GREETING: str = "你好"
```

常量不能被重新赋值。类中的 `const` 是静态常量。

## 5. 运算符

### 算术

| 运算 | 说明 |
|---|---|
| `a + b` | 加法；字符串、列表拼接；`str + char` 拼接 |
| `a - b` | 减法；集合差；`char - char` 得到 `int` |
| `a * b` | 乘法；`str * int`、`char * int`（例如 `'-' * 20`）、`list * int` 重复 |
| `a / b` | **总是浮点除法**：`7 / 2 == 3.5` |
| `a // b` | 向下取整除法：`-7 // 2 == -4` |
| `a % b` | 取模，结果与除数同号：`-7 % 3 == 2` |
| `a ** b` | 乘方；整数的负数次幂请用浮点数 |
| `-a` `+a` `~a` | 取负、正号、按位取反 |

整数除以零抛出 `ZeroDivisionError`；浮点数除以零得到 `inf` 或 `nan`。混合 `int` 与 `float` 运算的结果是 `float`。

### 比较

`==` `!=` `<` `>` `<=` `>=` 可以链式使用：`0 <= x < 10` 等价于 `0 <= x and x < 10`（`x` 只求值一次）。

- 列表、字典、集合、元组按内容比较；
- 类的对象默认按身份比较，定义了 `__eq__` 时调用它；
- 结构体按字段比较；
- 元组可以比较大小（逐个元素）。

### 逻辑

`and` `or` `not`，也可以写作 `&&` `||` `!`，结果都是 `bool`，`and`/`or` 短路求值。

### 位运算

`&` `|` `^` `<<` `>>`（整数）；`&` `|` `^` `-` 也用于集合的交、并、对称差、差；`dict | dict` 合并字典。

### 成员与类型

| 表达式 | 说明 |
|---|---|
| `x in xs`、`x not in xs` | 列表/集合/字典（键）/字符串（子串或字符）/实现了 `__contains__` 的类型 |
| `x is T`、`x is not T` | 运行时类型判断（用于 `any`、类、接口），判断后 `x` 会被窄化 |
| `x is null` | 等价于 `x == null` |
| `x as T` | 转换：数字之间转换、向下转型（失败抛出 `TypeError`），或显式写出隐式转换（`null as str?`） |
| `x as? T` | 安全转型：失败时得到 `null`，结果类型为 `T?` |

### 空值运算

| 表达式 | 说明 |
|---|---|
| `a?.b`、`a?.f()` | `a` 为 `null` 时结果为 `null`，否则访问成员 |
| `a ?? b` | `a` 不为 `null` 时取 `a`，否则取 `b`（`b` 只在需要时求值） |
| `a!` | 断言非空：`a` 为 `null` 时抛出 `NullError` |

### 条件表达式

```python
grade = "及格" if score >= 60 else "不及格"
```

### 优先级（从低到高）

| 优先级 | 运算符 |
|---|---|
| 0 | `x := ...`（赋值表达式） |
| 1 | `x => ...`（lambda） |
| 2 | `a if c else b` |
| 3 | `??`（右结合） |
| 4 | `or` `\|\|` |
| 5 | `and` `&&` |
| 6 | `not` `!` |
| 7 | 比较 `== != < > <= >= in not in is is not` |
| 8 | `\|` |
| 9 | `^` |
| 10 | `&` |
| 11 | `<<` `>>` |
| 12 | `+` `-` |
| 13 | `*` `/` `//` `%` |
| 14 | `as` `as?` |
| 15 | 一元 `-` `+` `~` |
| 16 | `**`（右结合） |
| 17 | `await` |
| 18 | 调用 `f()`、下标 `a[i]`、切片 `a[i:j:k]`、成员 `a.b`、`a?.b`、`a!` |

### 下标与切片

列表、字符串支持负下标（`xs[-1]` 是最后一个元素）和切片 `xs[start:stop:step]`（结果是新的列表/字符串）。元组的下标必须是常量：`t[0]`，也可以写作 `t.0`。

列表的切片可以被赋值和删除（与 Python 相同）：

```python
xs = [1, 2, 3, 4, 5]
xs[1:3] = [20, 30, 35]    # 替换一段，长度可以不同：[1, 20, 30, 35, 4, 5]
xs[::2] = [0, 0, 0]       # 步长不为 1 时，个数必须与切片选中的元素相同
xs[1:1] = range(2)        # 右边可以是任何可迭代对象（这里是插入）
del xs[:2]                # 删除一段
del xs[::3]
```

### 字面量中的展开

列表、集合字面量中可以用 `*` 展开任何可迭代对象，字典字面量中可以用 `**` 展开字典（后面的键覆盖前面的）：

```python
merged = [*a, *b, 0]
letters = {*"hello", 'z'}
config = {**defaults, "debug": true, **overrides}
print(*xs, sep=", ")      # print 的参数也可以展开
```

## 6. 控制流

```python
if x > 0:
    ...
elif x == 0:
    ...
else:
    ...

while cond:
    ...

for i in range(10):            # range(stop)、range(start, stop)、range(start, stop, step)
    ...
for i, x in enumerate(xs):     # enumerate(可迭代对象, start=0)
    ...
for a, b in zip(xs, ys):
    ...
for k, v in d.items():         # 遍历字典的键值对；for k in d 遍历键
    ...
for c in "字符串":              # 遍历字符（char）
    ...
```

`break`、`continue`、`pass` 与 Python 相同。五行没有 `for ... else` 和 `while ... else`。

### 真值判断

`if`、`while`、`and`/`or`/`not` 的条件需要是 `bool`，此外还可以是：

- 可空值：非 `null` 为真（并且在分支中自动窄化）；
- `str`、`list`、`dict`、`set`：非空为真；
- 定义了 `__bool__` 或 `__len__` 的对象。

数字**不能**直接作为条件，请写 `x != 0`。

## 7. 函数

```python
def area(w: float, h: float = 1.0) -> float:
    return w * h
```

- 参数必须标注类型（方法的 `self` 除外）；没有 `-> 类型` 表示没有返回值；
- 有返回值的函数，所有执行路径都必须 `return`（否则编译错误）；
- 调用时可以使用关键字参数：`area(h=2.0, w=3.0)`；
- 默认值在每次调用时求值（不会像 Python 那样共享可变默认值）。

### 可变参数与仅关键字参数

```python
def log(*parts: str, sep: str = " ") -> str:     # parts 的类型是 list[str]
    return sep.join(parts)

log("a", "b", sep="-")
log(*["x", "y"])                                   # 展开列表

def connect(host: str, *, timeout: float = 5.0):  # * 之后的参数只能用关键字传递
    ...
```

### 返回多个值

```python
def divmod2(a: int, b: int) -> (int, int):
    return a // b, a % b

q, r = divmod2(17, 5)
```

### lambda 与函数值

```python
square = (x: int) => x * x
add = (a: int, b: int) => a + b
nums.map(x => x * 2)            # 参数类型可以从上下文推断
def apply(f: fn(int) -> int, x: int) -> int:
    return f(x)
```

lambda 的主体是一个表达式；需要多条语句时使用嵌套函数。

在需要函数值、并且参数类型已知的地方，内置函数、类型名（转换或构造）、泛型函数以及 `类型.方法` 都可以直接当作函数传递，编译器会把它们包装成等价的 lambda：

```python
sorted(words, key=len)                  # 等价于 key=w => len(w)
nums = list(map(int, input().split()))  # 类型名：转换
pts = list(map(Point, xs))              # 类名：构造
sorted(names, key=str.lower)            # 类型.方法：第一个参数是接收者
ps.map(Point.norm)
f: fn(float) -> int = round
```

### 嵌套函数与闭包

```python
def make_counter() -> fn() -> int:
    count = 0
    def inc() -> int:
        count += 1
        return count
    return inc
```

### 生成器

返回类型为 `iter[T]` 且包含 `yield` 的函数是生成器，惰性产生值：

```python
def countdown(n: int) -> iter[int]:
    while n > 0:
        yield n
        n -= 1

def chain(a: list[int], b: list[int]) -> iter[int]:
    yield from a
    yield from b
```

生成器表达式 `(x * x for x in xs)` 的类型也是 `iter[T]`。

### async 函数

```python
async def fetch(url: str) -> str:
    ...
t = fetch("a.com")        # 立即在新协程中开始执行，t 的类型是 Task[str]
page = await t            # 等待结果；任务中的异常会在这里重新抛出
pages = await [fetch(u) for u in urls]     # 等待一组任务
```

## 8. 类

```python
class Account:
    owner: str                      # 字段（必须有类型）
    balance: float = 0.0            # 带默认值的字段
    static count: int = 0           # 静态字段
    const LIMIT = 10000.0           # 静态常量

    def __init__(self, owner: str, balance: float = 0.0):
        self.owner = owner
        self.balance = balance
        Account.count += 1

    def deposit(self, amount: float):
        self.balance += amount

    static def create(owner: str) -> Account:
        return Account(owner, 100.0)
```

- 类的对象是**引用语义**：赋值和传参不复制对象；
- 方法的 `self` 参数可以省略不写（写上也可以）；
- 在 `__init__` 中第一次给 `self.x` 赋值也会声明字段（类型从值推断）；
- **没有 `__init__` 的类会自动生成构造函数**，参数就是所有字段（有默认值的字段是可选参数）：

```python
class Point:
    x: int
    y: int = 0

p = Point(1)          # Point(x=1, y=0)
q = Point(x=2, y=3)
print(p)              # 默认的字符串形式：Point(x=1, y=0)
```

### 继承

```python
class Animal:
    name: str
    def speak(self) -> str:
        return "……"
    def intro(self) -> str:
        return f"{self.name}：{self.speak()}"     # 虚方法调用

class Dog(Animal):
    override def speak(self) -> str:            # override 是可选的，写上会被检查
        return "汪"
```

- 单继承；所有实例方法都是虚方法；
- `super().方法(...)` 调用基类的实现，`super().__init__(...)` 调用基类构造函数；
- 子类没有 `__init__` 时继承基类的构造函数；
- 覆盖方法的签名必须与基类一致。

### 抽象类

```python
abstract class Shape:
    abstract def area(self) -> float
```

抽象类不能实例化；非抽象子类必须实现所有抽象方法。

### 属性

```python
class Temperature:
    _c: float = 0.0

    prop celsius -> float:           # 只读属性：代码块就是 getter
        return self._c

    prop fahrenheit -> float:
        get:
            return self._c * 9.0 / 5.0 + 32.0
        set(f):
            self._c = (f - 32.0) * 5.0 / 9.0

t = Temperature()
t.fahrenheit = 212.0
print(t.celsius)                     # 100.0
```

单行写法：`prop area -> float => self.w * self.h`。

### 私有成员

以 `_` 开头（但不是 `__x__` 形式）的成员只能在定义它的模块中访问。

### 特殊方法

| 方法 | 用途 |
|---|---|
| `__init__(self, ...)` | 构造函数 |
| `__str__(self) -> str` | `str(x)`、`print(x)`、f-字符串 |
| `__repr__(self) -> str` | `repr(x)`、`{x!r}`、作为容器元素显示；没有 `__str__` 时 `str(x)`、`print(x)` 也使用它 |
| `__eq__(self, o) -> bool` | `==` 和 `!=` |
| `__lt__` `__le__` `__gt__` `__ge__` | `<` `<=` `>` `>=`；只定义 `__lt__` 时其余三个也可用，并且可以直接排序、求最值（见第 13 节 Comparable） |
| `__add__` `__sub__` `__mul__` `__truediv__` `__floordiv__` `__mod__` `__pow__` | `+ - * / // % **` |
| `__radd__` `__rsub__` `__rmul__` … | 左操作数不支持时的反向运算（如 `2 * v`） |
| `__and__` `__or__` `__xor__` `__lshift__` `__rshift__` | 位运算 |
| `__neg__` `__pos__` `__invert__` | 一元 `-` `+` `~` |
| `__len__(self) -> int` | `len(x)`，也用于真值判断 |
| `__bool__(self) -> bool` | 真值判断 |
| `__getitem__(self, k) -> V` | `x[k]` |
| `__setitem__(self, k, v)` | `x[k] = v` |
| `__contains__(self, v) -> bool` | `v in x` |
| `__iter__(self) -> iter[T]` | `for v in x`、`list(x)` |
| `__enter__(self)` / `__exit__(self)` | `with` 语句 |

## 9. 结构体 struct

`struct` 是**值类型**：赋值、传参、放进列表都会复制；按字段比较相等；字段都可哈希时可以作为字典的键或集合的元素。

```python
struct Vec:
    x: float
    y: float

    def __add__(self, o: Vec) -> Vec:
        return Vec(self.x + o.x, self.y + o.y)

    def scale(self, k: float):       # 修改 self 的方法
        self.x *= k
        self.y *= k

a = Vec(1.0, 2.0)
b = a              # 复制
b.scale(10.0)      # a 不受影响
```

结构体不能继承，但可以实现接口。修改 `self` 的方法只能在“可寻址”的值上调用（变量、字段、列表元素），不能在函数返回值、字典元素等临时值上调用（编译器会报错）。

结构体不能直接或间接地按值包含自己（例如字段 `next: Node?`），链表、树这类结构请用 `class`，或者把元素放进列表。

接口要求的方法如果会修改 `self`，结构体就不能当作这个接口使用（结构体转换为接口时会被复制，通过接口所做的修改不会作用到原来的值上），编译器会报错；这种情况请改用 `class`。

## 10. 接口

```python
interface Shape:
    def area(self) -> float
    prop name -> str

interface Solid(Shape):              # 接口可以嵌入其它接口
    def volume(self) -> float
```

接口是**结构化**的（与 Go 相同）：任何类、结构体或枚举，只要拥有接口要求的全部方法与属性（签名一致），就自动实现了该接口。字段可以满足只读属性的要求。

也可以在类声明中写出要实现的接口，编译器会检查是否真的实现了：

```python
class Square(Shape):
    side: float
    name: str = "正方形"
    def area(self) -> float:
        return self.side ** 2
```

接口类型的值在运行时可以用 `is` / `as` / `match` 判断具体类型。

接口本身只声明要求；带实现的公共方法可以用 `extend 接口名:` 添加，所有实现了该接口的类型都能使用（见第 19 节“接口的扩展方法”）。预导入的 `Comparable[T]` 接口用于自定义类型的排序（见第 13 节）。

## 11. 枚举与代数数据类型

### 简单枚举

```python
enum Color:
    Red
    Green = 5
    Blue

    def is_warm(self) -> bool:
        return self == Color.Red

c = Color.Blue
print(c, c.name, c.value)          # Color.Blue Blue 6
print(Color.values())              # [Color.Red, Color.Green, Color.Blue]
print(Color.from_value(5))         # Color.Green
print(c as int, 5 as Color)
```

### 带数据的枚举（代数数据类型 / 密封类）

只要有一个成员带括号，枚举就是代数数据类型，每个成员可以携带不同的数据：

```python
enum Shape:
    Circle(r: float)
    Rect(w: float, h: float)
    Empty

s = Shape.Circle(2.0)
print(s)                           # Shape.Circle(r=2.0)
```

成员的数据通过 `match` 取出。带数据的枚举可以是泛型的：

```python
enum Result[T]:
    Ok(value: T)
    Err(message: str)

r = Result.Ok(42)                  # 推断为 Result[int]
e = Result[int].Err("失败")        # 无法推断时写出类型实参
```

## 12. 模式匹配 match

```python
match value:
    case 0:
        ...
    case 1 | 2 | 3:                # 或模式
        ...
    case n if n < 0:               # 绑定变量 + 守卫
        ...
    case _:                        # 通配
        ...
```

| 模式 | 例子 | 说明 |
|---|---|---|
| 字面量 | `case 42`、`case "a"`、`case 'x'`、`case -1`、`case true` | 与值比较 |
| `null` | `case null` | 匹配空值 |
| 通配 | `case _` | 匹配任何值 |
| 捕获 | `case x` | 匹配任何值并绑定到 `x` |
| 常量 / 枚举成员 | `case MAX`、`case Color.Red`、`case Red` | 与值比较（主体是枚举时可以省略类型名） |
| 枚举数据 | `case Circle(r)`、`case Rect(w=w, h=_)` | 匹配成员并解构字段 |
| 类 / 结构体 | `case Point(x, 0)`、`case Point(y=yy)` | 类型判断并按字段解构（位置参数按字段声明顺序） |
| 类型 | `case int n`、`case Dog d`、`case list[int] xs`、`case Dog` | 运行时类型判断（主体是 `any`、类或接口） |
| 元组 | `case (0, y)` | 按位置匹配 |
| 列表 | `case []`、`case [x]`、`case [first, *rest]` | 按长度和元素匹配 |
| as | `case Circle(r) as c` | 匹配后把整个值绑定到 `c` |

匹配枚举时，如果没有覆盖全部成员（也没有 `case _`），编译器会给出警告。`match` 覆盖了所有情况时，函数末尾不需要额外的 `return`。

## 13. 泛型

```python
def first[T](xs: list[T]) -> T?:
    return xs[0] if len(xs) > 0 else null

class Box[T]:
    value: T
    def map[U](self, f: fn(T) -> U) -> Box[U]:
        return Box(f(self.value))

b = Box(5)                         # 类型实参从参数推断：Box[int]
s = Box[str]("x")                  # 也可以显式写出
```

### 约束

| 约束 | 允许的类型 | 允许的操作 |
|---|---|---|
| （无）`any` | 任何类型 | 赋值、传递、`==`（深度比较）、打印 |
| `Hashable` | 可哈希的类型 | 作为字典的键、集合元素 |
| `Ordered` | 数字、`str`、`char` | `< > <= >=`、`+` |
| `Number` | 数字 | 算术运算 |
| `Integer` | 整数 | 算术、`//`、`%`、位运算 |
| 接口名 | 实现了该接口的类型 | 调用接口方法、接口的扩展方法 |
| `Comparable[T]` | 定义了 `__lt__(self, other: T) -> bool` 的类型 | `< > <= >=`、`sorted` `min` `max`、`xs.sort()` 等 |
| `Sortable` | 能比较大小的类型：`Ordered` 的类型、实现了 `Comparable` 的类型，以及由它们组成的元组 | `< > <= >=`、`sorted` `min` `max`、`xs.sort()` 等 |

```python
def total[T: Number](xs: list[T]) -> T:
    s: T = 0
    for x in xs:
        s += x
    return s

def count[K: Hashable](items: list[K]) -> dict[K, int]: ...
```

`Sortable` 是 `sorted()` 能接受的元素的总称，常用于需要比较大小、又希望支持元组的泛型代码（例如堆中的 `(优先级, 数据)`）：

```python
def smallest[T: Sortable](xs: list[T]) -> T: ...
smallest([3, 1, 2])
smallest([("b", 2), ("a", 9)])       # 元组按元素依次比较
```

只需要数字、字符串时用 `Ordered` 更快（并且支持 `+`）。

接口约束中可以引用类型参数自己（F 界约束），例如 `T: Comparable[T]` 表示“能与同类型的值比较”；同一组中的其它类型参数也可以出现在约束里，例如 `[K, V: Container[K]]`。

泛型方法不能被子类覆盖；嵌套函数不能是泛型的。

### Comparable：自定义类型的排序

预导入的接口 `Comparable[T]` 只要求一个方法：

```python
interface Comparable[T]:
    def __lt__(self, other: T) -> bool
```

定义了 `__lt__(self, other: 本类型) -> bool` 的类、结构体、枚举（以及嵌入了 `Comparable[自身]` 的接口）就实现了 `Comparable[本类型]`，可以像数字、字符串一样直接排序和求最值：`sorted(xs)`、`min(...)` / `max(...)`（包括 `default=`）、`xs.sort()`、`xs.sorted()`、`xs.min()`、`xs.max()`。排序是稳定的；`reverse=true` 时相等的元素仍保持原来的先后顺序。只定义了 `__lt__` 时，`a > b`、`a <= b`、`a >= b` 分别按 `b < a`、`not (b < a)`、`not (a < b)` 计算。

```python
struct Version:
    major: int
    minor: int
    def __lt__(self, other: Version) -> bool:
        return (self.major, self.minor) < (other.major, other.minor)

vs = [Version(1, 2), Version(0, 9), Version(1, 0)]
print(sorted(vs), max(vs), vs.min(), Version(1, 0) <= Version(1, 2))
vs.sort(reverse=true)

def smallest[T: Comparable[T]](xs: list[T]) -> T:
    best = xs[0]
    for x in xs:
        if x < best:          # 使用约束中的 __lt__
            best = x
    return best
```

注意：

- `__lt__` 的参数类型必须就是元素类型本身。`Animal` 定义了 `__lt__(self, o: Animal)` 时，`list[Animal]` 可以直接排序，但 `list[Dog]` 不行——可以把列表写成 `list[Animal]`，或者提供 `key=`；
- 数字、`str`、`char` 等内置类型没有 `__lt__` 方法，不满足 `Comparable`；只需要支持这些类型时用约束 `Ordered`；
- 实现了 `Comparable` 的值也可以作为元组的元素参与比较（元组按元素依次比较），或者作为 `key=` 函数的返回值：`sorted(jobs, key=j => (j.version, j.name))`。

## 14. 空安全

非可空类型的变量永远不能为 `null`：

```python
s: str = null        # 错误
t: str? = null       # 正确
print(t.upper())     # 错误：值可能为 null
```

访问可空值的成员需要先确认它不是 `null`。编译器会在以下情况自动把变量**窄化**为非空类型：

```python
if t != null:            # 或 if t:、if t is not null:
    print(t.upper())

if t == null:
    return
print(t.upper())         # 提前返回之后

if t != null and len(t) > 3:  # and 的右侧
    ...

while node != null:      # 循环条件
    node = node.next
```

窄化只适用于局部变量与参数（以及模块顶层代码中的全局变量）；对象的字段需要先赋给局部变量，或者使用 `?.`、`??`、`!`。`x is Dog` 也会把 `x` 窄化为 `Dog`。

字典的 `d.get(k)` 返回 `V?`，列表的 `xs.first()`、`xs.get(i)` 也返回可空值。

## 15. 异常

```python
class ParseError(Exception):
    line: int
    def __init__(self, message: str, line: int):
        super().__init__(message)
        self.line = line

try:
    parse(text)
except ParseError as e:
    print(f"第 {e.line} 行：{e}")
except (ValueError, KeyError) as e:
    print("其它错误：", e.message)
except:                             # 捕获所有异常
    raise                           # 重新抛出当前异常
else:
    print("没有异常时执行")
finally:
    print("无论如何都执行")
```

- 只能抛出 `Exception` 的子类；`raise ValueError` 等价于 `raise ValueError()`；
- 异常的 `message` 字段保存消息，`str(e)` 调用 `__str__`（默认返回消息）；
- `try` 中的 `return`、`break`、`continue` 都能正确地穿过 `finally`；
- `finally` 中不能使用 `return`。

### 内置异常

```
Exception
├── ValueError ── JSONError
├── TypeError
├── IndexError
├── KeyError
├── ZeroDivisionError
├── NullError
├── RuntimeError
├── AssertionError
├── NotImplementedError
├── OverflowError
├── TimeoutError
├── ChannelClosedError
└── IOError ── OSError、FileNotFoundError、FileExistsError、PermissionError、EOFError
```

运行时错误会自动转换为对应的异常：列表下标越界 → `IndexError`，字典缺少键 → `KeyError`，整数除以零 → `ZeroDivisionError`，`x!` 断言失败 → `NullError`，`as` 转换失败 → `TypeError`，`int("abc")` → `ValueError`。

未捕获的异常会打印回溯并以状态 1 退出：

```

  文件 "bank.ae"，第 20 行，在 <模块 main>
    process(a)
  文件 "bank.ae"，第 6 行，在 Account.withdraw
    raise ValueError(f"余额不足：{self.balance} < {amount}")
ValueError: 余额不足：40.0 < 100.0
```

## 16. with 与 defer

`with` 在代码块开始时调用对象的 `__enter__()`，结束时（包括发生异常、`return`、`break`）调用 `__exit__()`；没有这两个方法但有 `close()` 的对象，结束时调用 `close()`。

```python
with open("data.txt") as f:
    for line in f:
        print(line)

with mu:                   # Mutex：进入时加锁，离开时解锁
    counter += 1

with a as x, b as y:       # 多个资源，按相反顺序释放
    ...
```

`defer` 让一个调用在函数结束时执行（Go 风格），多个 `defer` 按后进先出的顺序执行；调用的参数在 `defer` 语句处立即求值：

```python
def process():
    f = open("log.txt", "a")
    defer f.close()
    f.write("...")
```

`defer` 不能写在 `try`/`with` 内部（请使用 `finally`），也不能用于生成器。

## 17. 并发

### go 协程

`go 调用` 在新的协程中执行一个函数调用；参数在启动前求值。协程中未捕获的异常会终止整个程序并打印回溯。

```python
go worker(1, jobs)
```

### 通道

```python
ch = chan[int]()          # 无缓冲通道
buf = chan[str](100)      # 带缓冲的通道
ch.send(1)                # 发送（通道已关闭时抛出 ChannelClosedError）
v = ch.recv()             # 接收（通道已关闭且为空时抛出 ChannelClosedError）
ch.close()
for v in ch:              # 一直接收，直到通道关闭
    ...
ch.try_recv()             # 非阻塞接收，返回 T?
```

### select

```python
select:
    case msg = inbox.recv():
        print(msg)
    case outbox.send(42):
        print("发送成功")
    case time.after(1.0).recv():
        print("超时")
    default:
        print("都没有准备好")
```

### 同步原语

| 类型 | 方法 |
|---|---|
| `Mutex()` | `lock()` `unlock()` `try_lock()`，可用于 `with` |
| `RWMutex()` | `lock()` `unlock()` `rlock()` `runlock()` |
| `WaitGroup()` | `add(n=1)` `done()` `wait()` `spawn(f)`（启动协程并自动计数） |
| `AtomicInt(初值=0)` | `get()` `set(v)` `add(d)` `incr()` `compare_and_swap(old, new)` |

多个协程同时修改同一个列表或字典时，必须用 `Mutex` 保护。

### async / await

见第 7 节。`gather(tasks)` 等价于 `await tasks`；`xs.parallel_map(f)` 并行地对每个元素调用 `f`。`Task` 还有 `done()`（是否完成）和 `wait_for(秒)`（限时等待）方法。

## 18. 模块

每个 `.ae` 文件是一个模块。

```python
import math                       # 标准库模块
import utils                      # 同目录下的 utils.ae
import geo.shapes                 # geo/shapes.ae，绑定名字 shapes
import geo.shapes as gs           # 起别名

```

- 查找顺序：导入者所在目录 → 主程序所在目录 → 标准库；
- 以 `_` 开头的名字是模块私有的，不能被导入；
- 模块的顶层代码在第一次被导入时执行一次，执行顺序是依赖顺序（被导入的模块先执行）；
- 不能循环导入；
- 其它模块的全局变量可以读取，但不能在模块外直接赋值。

## 19. 扩展方法

`extend` 为已有类型（包括内置类型）添加方法和只读属性（C# 风格）：

```python
extend str:
    def shout(self) -> str:
        return self.upper() + "！"

extend[T] list[T]:
    def second(self) -> T:
        return self[1]

extend int:
    def times(self, f: fn(int)):
        for i in range(self):
            f(i)

print("hi".shout(), [1, 2, 3].second())
3.times(i => print(i))
```

扩展方法不能与类型已有的成员重名；同一个类型的扩展方法可以按参数个数区分（重载）。以 `_` 开头的扩展成员只能在定义它的模块中使用。

### 接口的扩展方法

`extend` 的目标也可以是接口。这样定义的方法和属性适用于**所有实现了该接口的类型**——类、结构体、枚举、其他接口，以及以该接口为约束的类型参数，相当于 C# 的默认接口方法。这些方法不属于接口的要求，实现接口的类型不需要提供它们：

```python
interface Shape:
    def area(self) -> float

extend Shape:
    def describe(self) -> str:
        return f"面积 {self.area():.1f}"
    prop half -> float:
        return self.area() / 2.0

class Square:
    side: float
    def area(self) -> float:
        return self.side * self.side

print(Square(2.0).describe(), Square(2.0).half)   # 面积 4.0 2.0
shapes: list[Shape] = [Square(1.0)]
print([s.describe() for s in shapes])

def total_half[T: Shape](xs: list[T]) -> float:
    return sum(x.half for x in xs)
```

泛型接口的扩展可以带约束，只对满足约束的实现生效：

```python
interface Seq[T]:
    def at(self, i: int) -> T
    def size(self) -> int

extend[T: Ordered] Seq[T]:          # 元素可比较的序列才有 biggest()
    def biggest(self) -> T: ...
```

查找成员 `x.name` 时的顺序：

1. 类型自己的字段、方法、属性（包括继承来的）；
2. 类型自身的扩展（例如 `extend Square:`），然后是基类的扩展（近的基类优先）——类的扩展也适用于它的子类；
3. 类型实现的接口的扩展。多个接口都提供了同名扩展时，选最具体的接口（例如嵌入了另一个接口的接口）；两个互不相关的接口都提供时报告歧义，可以先用 `as` 选定其中一个：`(x as HasA).hi()`。

同一层中参数个数不匹配时，会继续在后面的层中查找同名的扩展（例如基类扩展的 `tag(k)` 与子类扩展的 `tag()` 可以并存）。

扩展方法是**静态绑定**的：按表达式的静态类型选择扩展。通过接口（或基类）类型的值调用时，调用的总是接口（或基类）的扩展，即使值的实际类型自己也有同名的方法或扩展；直接通过具体类型调用时，类型自己的方法优先。

结构体修改 `self` 的方法不能满足接口的要求（见第 9 节），这样的结构体也不能调用该接口的扩展方法。

## 21. 与 Go 互操作

标准库就是这样实现的：带 `@go("...")` 的声明没有函数体，直接映射到 Go 代码。

```python
@go("strings.Repeat") def go_repeat(s: str, count: int) -> str
@go("math.Pi") const PI: float

@go("*rt.Mutex", ctor="rt.NewMutex")
class Mutex:
    def __init__(self)
    @go("Lock") def lock(self)
```

`@go` 的写法：

| 写法 | 生成的调用 |
|---|---|
| `"pkg.Func"` | `pkg.Func(参数...)`（方法上：接收者作为第一个参数） |
| `"path/to/pkg.Func"` | 导入 `path/to/pkg` 后调用 `pkg.Func(...)` |
| `".Method"` 或 `"Method"`（类中） | `接收者.Method(参数...)` |
| 含 `$` 的模板 | `$r` 接收者，`$1`…`$9` 参数，`$*` 全部参数，`$T1`… 类型实参 |

类型对应关系：`int`→`int`，`float`→`float64`，`str`→`string`，`bool`→`bool`，`char`→`rt.Char`，`list[T]`→`*rt.List[T]`，`dict[K,V]`→`*rt.Dict[K,V]`，`T?`→`rt.Opt[T]`，`fn(A)->R`→`func(A) R`，`iter[T]`→`iter.Seq[T]`。这是高级功能，签名不匹配时会出现 Go 编译错误。

## 22. 与 Python 的主要区别

| Python | 五行 |
|---|---|
| `True` `False` `None` | `true` `false` `null` |
| `'字符串'` | `"字符串"`（单引号是字符 `char`） |
| `lambda x: x * 2` | `x => x * 2` |
| `def f(x):` | `def f(x: int) -> int:`（参数需要类型） |
| 变量可以改变类型 | 变量的类型在第一次赋值时确定 |
| `s[i]` 得到字符串 | `s[i]` 得到 `char`；`str(c)` 转换为字符串 |
| `print(1 if x else 0)`（任意值作条件） | 数字不能作为条件，写 `x != 0` |
| `a or b` 返回操作数之一 | `and`/`or` 返回 `bool`；默认值用 `a ?? b` |
| `@staticmethod`、`@property`、`@dataclass` | `static def`、`prop`、自动构造函数 |
| `if __name__ == "__main__":` | `def main():` |
| `Graph = dict[str, int]`（类型别名） | `type Graph = dict[str, int]` |
| `map(str, xs)` 中的 `str` 是一个函数 | 内置函数、类型名只在需要函数值的地方才能当作值使用 |
| 大整数 | 64 位整数，溢出回绕 |
| `%` / `.format()` 格式化 | f-字符串 |
| 列表推导式中的 lambda 晚绑定 | 每次迭代捕获新的变量 |
| 动态类型、运行时报错 | 编译时类型检查、空安全检查 |
| 解释执行 | 编译为原生可执行文件 |
