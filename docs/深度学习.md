# 深度学习：tensor、tensor.nn、tensor.optim

Aether 自带一个深度学习框架：多维张量、自动求导、常用的神经网络层、损失函数与优化器，接口与 PyTorch 基本一致。
张量可以放在 CPU 或 GPU 上；GPU 后端使用显卡驱动自带的 **OpenCL**，NVIDIA、AMD、Intel 显卡都可以使用，
**不需要安装 CUDA、ROCm 或任何 SDK**，也不需要 C 编译器。

```python
import tensor
import tensor.nn as nn
import tensor.optim as optim
from tensor import Tensor

class MLP(nn.Module):
    fc1: nn.Linear
    fc2: nn.Linear

    def __init__(self):
        self.fc1 = nn.Linear(2, 64)
        self.fc2 = nn.Linear(64, 3)

    def forward(self, x: Tensor) -> Tensor:
        return self.fc2(self.fc1(x).relu())

tensor.set_default_device("gpu" if tensor.gpu_available() else "cpu")
model = MLP()
opt = optim.Adam(model.parameters(), lr=0.01)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(100):
    for idx in tensor.batches(len(x), 64):           # 打乱后分批
        loss = loss_fn(model(x.index_select(0, idx)), y.index_select(0, idx))
        opt.zero_grad()
        loss.backward()
        opt.step()
```

完整的示例见 `examples/deep_learning.ae`（多层感知机）与 `examples/cnn.ae`（卷积网络、BatchNorm、保存与读取模型）。

## 1. 张量

张量是 `float32` 的多维数组（行优先、连续存储）。类别标签、下标等整数也以浮点数存储。

### 创建

| 函数 | 说明 |
|---|---|
| `tensor.tensor(data, shape=null)` | 由 `list[float]` 创建；给出 `shape` 时按形状排列：`tensor.tensor([1, 2, 3, 4], [2, 2])` |
| `tensor.from_rows(rows)` | 由 `list[list[float]]` 创建二维张量 |
| `tensor.from_ints(data, shape=null)` | 由 `list[int]` 创建（例如类别标签） |
| `tensor.scalar(v)` | 零维张量 |
| `tensor.zeros(*shape)` `tensor.ones(*shape)` | `tensor.zeros(2, 3)`；形状在列表中时写 `tensor.zeros(*shape)` |
| `tensor.full(shape, value)` `zeros_like(t)` `ones_like(t)` | |
| `tensor.arange(stop)` `arange(start, stop, step=1)` | `[start, stop)` 中等间隔的数 |
| `tensor.linspace(start, stop, steps)` `tensor.eye(n)` | |
| `tensor.randn(*shape)` `tensor.rand(*shape)` | 标准正态分布、`[0, 1)` 均匀分布 |
| `tensor.uniform(shape, low, high)` `tensor.randint(low, high, shape)` `tensor.randperm(n)` | |
| `tensor.manual_seed(n)` | 设置随机数种子；之后的结果可以重现，**CPU 与 GPU 上生成的随机数完全相同** |

新张量放在默认设备上（见第 3 节）。

### 属性与转换

| 成员 | 说明 |
|---|---|
| `t.shape` `t.ndim` `t.numel()` `t.size(dim)` `len(t)` | 形状（`list[int]`）、维数、元素个数、某一维的长度、第 0 维的长度 |
| `t.device` | `"cpu"` 或 `"gpu"` |
| `t.item()` | 只有一个元素的张量的值（`float`） |
| `t.tolist()` `t.rows()` | 所有元素（展平为 `list[float]`）、二维张量的各行 |
| `t[i]` | 第 0 维上的第 `i` 项（支持负数下标） |
| `print(t)` | `tensor([[0.0000, 1.0000], [2.0000, 3.0000]], device=gpu, requires_grad=true)` |

### 运算

运算符 `+ - * / **` 可以用于两个张量（按形状**广播**，规则与 NumPy/PyTorch 相同），也可以用于张量与数：
`x * 2`、`1 - x`、`2 ** x`。`a @ b` 是矩阵乘法：支持向量、矩阵，以及带批次维的张量（`[B, m, k] @ [B, k, n]`、`[B, m, k] @ [k, n]`）。

| 类别 | 方法 |
|---|---|
| 逐元素 | `exp` `log` `sqrt` `abs` `square` `pow(p)` `sin` `cos` `relu` `leaky_relu(slope=0.01)` `sigmoid` `tanh` `gelu` `clamp(min, max)` `maximum(t)` `minimum(t)` `-t` |
| 归约（不给 `dim` 时对所有元素） | `sum` `mean` `var` `std`（`unbiased=true`）`max` `min` `argmax` `argmin`，参数 `dim=null, keepdim=false` |
| softmax | `softmax(dim=-1)` `log_softmax(dim=-1)` |
| 比较（结果是 0/1 张量） | `eq(t)` `gt(t)` `lt(t)` `ge(t)` `le(t)` `gt_scalar(v)` `lt_scalar(v)`；`allclose(t, rtol=1e-5, atol=1e-8)` 返回 `bool` |
| 形状 | `reshape(*shape)`（可以有一个 `-1`）`view(*shape)` `flatten(start_dim=0, end_dim=-1)` `unsqueeze(dim)` `squeeze(dim=null)` `permute(*dims)` `transpose(d0, d1)` `t.T` `expand(*shape)` |
| 选取 | `narrow(dim, start, length)` `slice(dim, start, end=null)`（Python 风格，支持负数）`index_select(dim, index)` |
| 组合 | `tensor.cat(ts, dim=0)` `tensor.stack(ts, dim=0)` `tensor.where(cond, a, b)` `tensor.one_hot(index, num_classes)` |

`reshape`、`view`、`flatten`、`squeeze`、`unsqueeze` 与原张量共享数据；其余运算都返回新张量。

## 2. 自动求导

```python
x = tensor.tensor([1.0, 2.0, 3.0]).requires_grad_()
y = (x * x + 3 * x).sum()
y.backward()
print(x.grad)              # tensor([5.0000, 7.0000, 9.0000])
```

- `requires_grad_(flag=true)` 让叶子张量记录梯度；由它计算出的张量会记录计算图（`t.grad_fn` 是产生它的运算名，`t.is_leaf` 判断是否是叶子）。
- `loss.backward()` 从标量开始反向传播，把梯度**累加**到叶子张量的 `grad`（类型是 `Tensor?`）上；非标量张量需要给出梯度：`y.backward(g)`。每次前向计算只能反向传播一次。
- `t.zero_grad()` 清除梯度；`t.detach()` 返回共享数据但不参与求导的张量；`t.clone()` 复制数据（保留求导关系）；`t.copy_(src)` 原地复制数据。
- `with tensor.no_grad():` 块中的计算不记录计算图（推理、手动更新参数时使用）；`tensor.is_grad_enabled()`。

所有可求导的运算都用数值梯度做了测试（`assets/rt/rttensor/tensor_test.go`）。

## 3. 设备与 GPU

```python
print(tensor.gpu_available(), tensor.device_info())
# true NVIDIA GeForce RTX 3050 Laptop GPU（NVIDIA Corporation，OpenCL 3.0 CUDA，16 个计算单元，4.0 GB 显存）

tensor.set_default_device("gpu")     # 之后创建的张量都放在 GPU 上
x = tensor.randn(1024, 1024)
y = x.to("cpu")                      # 复制到另一个设备；也可以写 x.cpu()、x.gpu()（或 x.cuda()）
model.to("gpu")                      # 模块的参数原地移动
```

| 函数 | 说明 |
|---|---|
| `tensor.set_default_device(d)` `tensor.default_device()` | `"cpu"` 或 `"gpu"`（`"cuda"`、`"rocm"`、`"opencl"` 是 `"gpu"` 的别名） |
| `tensor.gpu_available()` `tensor.device_info()` `tensor.gpu_devices()` | 是否有 GPU、所选 GPU 的信息、所有 GPU 的列表 |
| `tensor.synchronize()` | 等待 GPU 上已提交的计算完成（GPU 是异步执行的，计时前需要同步） |
| `tensor.gpu_memory_allocated()` `tensor.empty_cache()` | 张量占用的显存字节数；把缓存的空闲显存还给驱动 |

- 参与同一个运算的张量必须在同一设备上（否则抛出 `RuntimeError`）；作为下标的张量（`index_select`、`embedding`、交叉熵的类别标签）例外，会自动复制过去。
- 有多块显卡时默认选择独立显卡；环境变量 `AETHER_GPU=序号` 可以指定使用 `gpu_devices()` 中的哪一块。
- 第一次使用 GPU 时驱动会编译内核，需要几百毫秒。
- 显存由框架管理：张量被垃圾回收后，它的显存放回缓存池复用；分配的显存累计超过阈值（显存的 1/8）时会主动触发垃圾回收，所以显存占用大约是“正在使用的张量 + 阈值”。

**支持的硬件**：任何提供 OpenCL 1.2 以上驱动的 GPU——NVIDIA（GeForce/RTX/Quadro/Tesla）、AMD（Radeon）、Intel（核显、Arc）。目前 GPU 后端只在 **Windows** 上可用；Linux、macOS 上使用 CPU（见第 8 节）。

## 4. 神经网络：tensor.nn

### 模块

自定义模型继承 `nn.Module`，把层和参数放在字段中，实现 `forward(x)`；`model(x)` 就是 `model.forward(x)`。
模型的**参数**是字段中需要梯度的张量，包括子模块、列表、字典中的（以 `_` 开头的字段不算）；
不需要梯度的张量字段（例如 BatchNorm 的滑动平均）是缓冲区，不参与训练，但会随模型移动设备、保存与读取。

| 方法 | 说明 |
|---|---|
| `parameters()` `named_parameters()` `num_parameters()` | 可训练的参数（传给优化器）、带名字的参数（如 `"fc1.weight"`）、参数的元素总数 |
| `named_tensors()` `modules()` | 参数与缓冲区、自己与所有子模块 |
| `train(mode=true)` `eval()` | 训练模式、推理模式（影响 Dropout、BatchNorm；对所有子模块生效） |
| `to(device)` `cpu()` `gpu()` | 原地移动参数与缓冲区（请在创建优化器之前调用） |
| `zero_grad()` | 清除所有参数的梯度 |
| `state_dict()` `load_state_dict(d, strict=true)` | 名字到张量的字典；读入时检查名字与形状 |
| `save(path)` `load(path)` | 保存、读取参数（也可以用 `tensor.save(model.state_dict(), path)`、`tensor.load(path)`） |
| `print(model)` | 显示模型的结构 |

### 层

| 层 | 说明 |
|---|---|
| `Linear(in_features, out_features, bias=true)` | `y = x @ weightᵀ + bias`，输入的形状为 `[..., in_features]` |
| `Conv2d(in_channels, out_channels, kernel_size, stride=1, padding=0, bias=true)` | 输入 `[N, C, H, W]` |
| `MaxPool2d(kernel_size, stride=0, padding=0)` `AvgPool2d(kernel_size, stride=0)` | `stride` 为 0 时等于 `kernel_size` |
| `BatchNorm1d(n)` `BatchNorm2d(n)`（`eps=1e-5, momentum=0.1`） | 训练时用这一批的统计量并更新滑动平均，推理时用滑动平均 |
| `LayerNorm(n, eps=1e-5)` | 对最后一维归一化 |
| `Embedding(num, dim)` | 按下标取出 `weight` 的行；下标张量可以是任意形状 |
| `Dropout(p=0.5)` | 只在训练模式下起作用 |
| `ReLU()` `LeakyReLU(slope)` `Sigmoid()` `Tanh()` `GELU()` `Softmax(dim)` `LogSoftmax(dim)` `Flatten(start_dim=1)` `Identity()` | |
| `Sequential(*layers)` | 依次执行；支持 `seq[i]`、`len(seq)`、`seq.append(layer)` |

参数的初始化与 PyTorch 相同（`Linear`、`Conv2d` 为 `U(-1/√fan_in, 1/√fan_in)`）。

### 损失函数

| 类 | 函数形式 | 说明 |
|---|---|---|
| `CrossEntropyLoss()` | `tensor.cross_entropy(logits, target)` | `logits` 为 `[N, C]`，`target` 为 N 个类别下标 |
| `NLLLoss()` | `tensor.nll_loss(log_probs, target)` | 输入是 `log_softmax` 的结果 |
| `MSELoss()` `L1Loss()` | `tensor.mse_loss` `tensor.l1_loss` | |
| `BCELoss()` `BCEWithLogitsLoss()` | `tensor.binary_cross_entropy` `tensor.binary_cross_entropy_with_logits` | 二分类；后者输入未经 sigmoid 的值，数值更稳定 |

都有参数 `reduction`：`"mean"`（默认）、`"sum"` 或 `"none"`。`nn.clip_grad_norm_(params, max_norm)` 限制梯度的总范数。

各个层也有函数形式：`tensor.linear` `conv2d` `max_pool2d` `avg_pool2d` `dropout` `layer_norm` `batch_norm` `embedding` `relu` `softmax` 等。

## 5. 优化器：tensor.optim

| 优化器 | 说明 |
|---|---|
| `SGD(params, lr, momentum=0, weight_decay=0)` | 随机梯度下降（与 PyTorch 相同：第一步的动量缓冲区等于梯度） |
| `Adam(params, lr=0.001, betas=(0.9, 0.999), eps=1e-8, weight_decay=0)` | |
| `AdamW(params, lr=0.001, betas=(0.9, 0.999), eps=1e-8, weight_decay=0.01)` | 权重衰减直接作用于参数 |

方法：`step()`、`zero_grad()`、`set_lr(lr)`；属性 `lr`、`steps`。每一步对每个参数只运行一次融合的更新运算（在 GPU 上不需要把数据传回内存）。

学习率调度（每个 epoch 结束时调用 `step()`）：`StepLR(opt, step_size, gamma=0.1)`、`ExponentialLR(opt, gamma)`、`CosineAnnealingLR(opt, t_max, eta_min=0)`。

## 6. 与 PyTorch 的区别

| PyTorch | Aether |
|---|---|
| `torch.tensor([[1, 2], [3, 4]])` | `tensor.from_rows([[1.0, 2.0], [3.0, 4.0]])`，或 `tensor.tensor([1, 2, 3, 4], [2, 2])` |
| `x > 0`、`x == y` | `x.gt_scalar(0)`、`x.eq(y)`（Aether 的比较运算符必须返回 `bool`） |
| `x[1:3]`、`x[:, 0]` | `x.slice(0, 1, 3)`、`x.narrow(1, 0, 1)`；`x[i]` 可以用 |
| `values, idx = x.max(dim=1)` | `x.max(dim=1)` 与 `x.argmax(dim=1)` |
| `nn.Parameter(t)` | `t.requires_grad_()` 后放在模块的字段中 |
| `self.layers = nn.ModuleList([...])` | 字段类型写 `list[nn.Module]` 即可 |
| `with torch.no_grad():` | `with tensor.no_grad():` |
| `DataLoader(dataset, batch_size, shuffle=True)` | `for idx in tensor.batches(n, batch_size): x.index_select(0, idx)` |
| `x.cuda()`、`device="cuda"` | `x.gpu()`（也可以写 `x.cuda()`）、`"gpu"`；AMD、Intel 显卡也一样 |

## 7. 实现

代码在 `assets/rt/rttensor`（Go），只有导入了 `tensor` 的程序才会链接它。

- **后端接口**：所有张量运算都归结为约 25 个基本运算（逐元素、广播、按维归约、矩阵乘法、softmax、重排、im2col/col2im、池化、随机数、融合的优化器更新等）。CPU 后端用 Go 实现并在多个核心上并行；GPU 后端是一份 OpenCL C 内核（`kernels.go`），第一次使用时由驱动编译。增加新的硬件只需要实现这个接口。
- **调用 OpenCL**：在 Windows 上通过 `syscall` 直接调用驱动的 `OpenCL.dll`，不需要 cgo；所有命令提交到同一个按顺序执行的队列，读取结果时阻塞等待。
- **自动求导**：每个运算在需要时记录输入与反向函数；`backward()` 按拓扑顺序计算梯度并在使用后释放中间结果。反向函数本身也由基本运算组成，所以在 GPU 上反向传播同样在 GPU 上进行。
- **随机数**：计数器式的哈希随机数，第 i 个随机数只取决于种子和 i，所以 CPU 与 GPU 的结果相同，并行生成也不会改变结果。
- **矩阵乘法**：GPU 上每个工作组计算 64×64 的输出块、每个工作项计算 4×4 个元素（局部内存分块）；卷积用 im2col 转换为矩阵乘法。
- **测试**：每个可求导运算的数值梯度检查、GPU 与 CPU 的结果对比（前向与反向）、显存回收的测试，以及 `tests/run/23_tensor.ae`。

## 8. 性能与限制

在一台笔记本（AMD Ryzen 5 5600H，NVIDIA RTX 3050 Laptop 4 GB）上：

| 测试 | CPU | GPU |
|---|---:|---:|
| 2048×2048 矩阵乘法 | 29 GFLOPS | 1335 GFLOPS |
| `examples/deep_learning.ae`（MLP，900 步训练） | 2.2 秒 | 0.65 秒 |
| `examples/cnn.ae`（卷积网络，6 轮） | 9.9 秒 | 1.6 秒 |

当前的限制：

- GPU 后端目前只在 Windows 上可用。Aether 构建程序时不使用 cgo，在 Linux/macOS 上还不能动态加载 `libOpenCL.so`；这些系统上使用 CPU 后端。
- 不支持华为昇腾（Ascend）NPU：它不提供 OpenCL，需要通过 CANN 工具链接入，可以作为一个新的后端实现。
- 只有 `float32`；没有半精度、混合精度训练与整数张量。
- CPU 上的矩阵乘法是 Go 代码，没有使用 SIMD 指令，比 MKL/OpenBLAS 慢一个数量级；GPU 上的矩阵乘法也没有达到 cuBLAS 的水平。
- 没有分布式训练、计算图编译与算子融合、`LSTM`/`Transformer` 等更高级的层（可以用现有的运算组合出来）。
