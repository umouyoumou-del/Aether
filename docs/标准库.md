# Aether 标准库

内置函数和内置类型的方法无需导入即可使用；模块需要 `import`。标准库的源码在 `assets/lib/*.ae`（声明）与 `assets/rt/*.go`（实现）。

## http

def hello(req: http.Request) -> http.Response:
    return http.text(f"你好，{req.query("name") ?? "世界"}！")

## heapq

用 `list[T]`（`T: Sortable`：数字、字符串、定义了 `__lt__` 的类型，或由它们组成的元组）表示的最小堆，用纯 Aether 代码实现（`assets/lib/heapq.ae`）：
`heappush(h, x)` `heappop(h) -> T` `heappushpop(h, x) -> T` `heapify(h)` `nlargest(n, items)` `nsmallest(n, items)`。

```python
import heapq
h: list[int] = []
for x in [5, 1, 8]:
    heapq.heappush(h, x)
print(heapq.heappop(h))      # 1

pq: list[(int, str)] = []    # 常见写法：(优先级, 数据)
heapq.heappush(pq, (2, "写代码"))
heapq.heappush(pq, (1, "喝水"))
pri, task = heapq.heappop(pq)
```

## itertools

用纯 Aether 代码实现（`assets/lib/itertools.ae`）。与 Python 不同：排列、组合、笛卡尔积的每一项是**列表**（Python 是元组），可以直接解构：`for a, b in combinations(xs, 2)`。

| 函数 | 说明 |
|---|---|
| `count(start=0, step=1)` `cycle(xs)` `repeat(x, times=-1)` | 无限（或有限）的序列 |
| `chain(*its)` `chain_from(iters)` | 依次连接；`chain_from` 相当于 Python 的 `chain.from_iterable` |
| `accumulate(xs, f=null, initial=null)` | 前缀和，或用二元函数累积：`accumulate(xs, max)` |
| `pairwise(xs)` | 相邻的两个元素：`(1, 2), (2, 3)` |
| `groupby(xs, key)` | 把连续的、键相同的元素分为一组，产生 `(键, 列表)` |
| `batched(xs, n)` | 每 `n` 个一组 |
| `islice(xs, stop)`、`islice(xs, start, stop, step=1)` | 切片（`stop` 为 -1 表示到结尾） |
| `takewhile(f, xs)` `dropwhile(f, xs)` `filterfalse(f, xs)` `compress(xs, selectors)` | 过滤 |

## datetime

```python
from datetime import datetime, date, timedelta

now = datetime.now()
week_ago = now - timedelta(days=7)
print(now.strftime("%Y-%m-%d %H:%M"), (now - week_ago).days)
d = date(2024, 2, 29)
print(d + timedelta(days=1), d.weekday(), d.isocalendar())
t = datetime.strptime("2024-07-14 09:30", "%Y-%m-%d %H:%M")
```

用纯 Aether 代码实现（`assets/lib/datetime.ae`），表示不带时区的本地时间（与 Python 的 naive datetime 相同），精确到微秒，年份范围 1 到 9999。三个类型都是**值类型**：可以比较、排序、作为字典的键。

| 类型 | 说明 |
|---|---|
| `timedelta(days=0, seconds=0, microseconds=0, milliseconds=0, minutes=0, hours=0, weeks=0)` | 时间间隔。属性 `days` `seconds` `microseconds`（`days` 可以为负，后两者总是非负）；`total_seconds()`；运算 `+ - ` 一元负号、`* 数字`、`/ 数字`、`// 整数`、比较 |
| `date(year, month, day)` | 日期。`date.today()` `date.fromisoformat(s)` `date.fromordinal(n)` `date.fromtimestamp(ts)`；属性 `year` `month` `day`；`weekday()`（星期一为 0）`isoweekday()` `isocalendar()` `toordinal()` `replace(...)` `isoformat()` `strftime(fmt)`；`日期 ± timedelta`、`日期 - 日期 -> timedelta` |
| `datetime(year, month, day, hour=0, minute=0, second=0, microsecond=0)` | 日期时间。`datetime.now()` `today()` `utcnow()` `fromtimestamp(ts)` `fromisoformat(s)` `strptime(s, fmt)` `combine(date, hour=0, ...)`；属性 `year` … `microsecond`；`date()` `timestamp()` `weekday()` `isoformat(sep='T')` `strftime(fmt)` `replace(...)`；`时间 ± timedelta`、`时间 - 时间 -> timedelta` |

`strftime` / `strptime` 支持 `%Y %m %d %H %M %S %f %y %b %B %a %A %j %p %I %%`。常量 `MINYEAR` `MAXYEAR`，`timedelta` 的边界 `min` `max` `resolution`。

## sym
