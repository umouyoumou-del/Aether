# 五行 (Aether) 标准库

内置函数和内置类型的方法无需导入即可使用；模块需要 `import`。标准库的源码在 `assets/lib/*.ae`（声明）与 `assets/rt/*.go`（实现）。

## http

```python
import http

def hello(req: http.Request) -> http.Response:
    return http.text(f"你好，{req.query("name") ?? "世界"}！")

server = http.Server()
server.get("/", hello)
server.get("/users/{id}", req => http.json({"id": req.param("id")}))
server.post("/echo", req => http.json(req.json()))
server.listen(":8080")
```

| 名字 | 说明 |
|---|---|
| `Server()` | `get(pattern, handler)` `post(...)` `route(method, pattern, handler)` `static(prefix, dir)` `listen(addr=":8080")`（阻塞）`start(addr=":0") -> str`（后台启动，返回地址）`stop()` `quiet()` |
| `Request` | 属性 `method` `path` `url` `body`；方法 `query(name)` `param(name)` `header(name)` `form(name)`（都返回 `str?`）、`json()` |
| `Response` | 属性 `status` `text` `ok`；方法 `json()` `header(name)` `set_header(name, value)` |
| `text(body, status=200)` `html(...)` `json(value, status=200)` `status(code, message="")` `redirect(url)` | 构造响应 |
| `get(url, timeout=30.0)` `post(url, body, content_type="application/json", timeout=30.0)` | HTTP 客户端 |

处理函数中未捕获的异常会被记录（含回溯）并返回 500。路由模式使用 Go 1.22 的语法，例如 `/files/{path...}`。

## heapq

用 `list[T]`（`T: Ordered`）表示的最小堆，用纯五行代码实现（`assets/lib/heapq.ae`）：
`heappush(h, x)` `heappop(h) -> T` `heappushpop(h, x) -> T` `heapify(h)` `nlargest(n, items)` `nsmallest(n, items)`。

```python
import heapq
h: list[int] = []
for x in [5, 1, 8]:
    heapq.heappush(h, x)
print(heapq.heappop(h))      # 1
```

## collections

同样用纯五行代码实现（`assets/lib/collections.ae`）：

| 类 | 说明 |
|---|---|
| `Deque[T]()` | 双端队列：`append` `appendleft` `pop` `popleft`（都是 O(1)）`peek() -> T?` `peek_last() -> T?` `to_list()`，支持 `len` 与 `for` |
| `PriorityQueue[T]()` | 优先队列：`push(item, priority=0.0)` `pop()` `peek() -> T?`，优先级小的先出，相同优先级先进先出 |
| `DefaultDict[K, V](factory)` | 访问不存在的键时用 `factory()` 创建值：`DefaultDict[str, int](() => 0)` |

```python
from collections import DefaultDict
groups = DefaultDict[str, list[str]](() => list[str]())
for w in ["apple", "banana", "avocado"]:
    groups[w[0:1]].append(w)
```
